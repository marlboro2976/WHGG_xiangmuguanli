## 1. 背景与目标

### 1.1 问题

现有"项目维度看板"仅按阶段个数、产业类别、申报月份、投资金额 TOP10 做静态展示：
- 无时间维度筛选，指标口径与领导层关注的**半年度/月度招商引资通报**不对齐；
- 看不到"当月签约了多少项目、当月落地了多少项目"以及对应的**明细清单**；
- 无法按**园区**视角对齐通报的汇报结构（签约个数/金额、到位资金、开工开业个数、FDI）。

### 1.2 目标

在统计看板内提供一套"以通报口径为导向、可下钻到明细"的项目统计分析页：

1. 顶部统一提供**时间区间筛选**（起止年月），所有指标/图表/明细联动；
2. 对齐通报的**总览指标口径**：签约项目数、签约金额、落地（开工开业）项目数、当年到位资金、FDI 项目数；
3. 单独统计并展示**当月签约项目、当月落地项目**，配套**明细表**与导出；
4. 以**园区（负责单位）**为主要对比维度，按需提供目标完成率。

### 1.3 需求输入与排除

- **引用通报内容**：总览段（签约个数/金额、当年到位资金、开工开业项目数、FDI）与"各园区招商情况"的对比结构；引用其"逐园区完成进度靠前/超时序"的呈现逻辑。
- **排除内容**（与项目数据无关、无字段支撑）：见商/出差、各类招商活动、重点活动明细、"周周有签约"活动、项目线索、国企尽调/认缴实缴出资/品牌活动、各行业主管部门（组织部/科创局等）文字性工作情况。

## 2. 用户与使用场景

### 2.1 用户

| 用户 | 诉求 |
| --- | --- |
| 管委会/园区领导 | 快速掌握某段时间全区及各园区的签约、落地、到资、FDI 完成情况 |
| 投促局统计分析岗 | 生成月度/半年度汇报数据，定位"当月签约/落地项目清单"，导出交付 |
| 园区招商经办 | 查看本园区区间内完成量与园区间差距 |

### 2.2 核心用户故事

1. 作为**领导/统计人员**，我要**只选一个起止月份区间**，使全页累计指标与图表按该区间重算，以便做半年/季度/月度汇报。
2. 作为**统计人员**，我要看到与通报一致的**总览指标卡**（签约项目数与金额、落地项目数、到位资金、FDI），以便直接引用到汇报。
3. 作为**统计人员**，我要看到**当月签约项目、当月落地项目**的统计数量，并打开**明细表**逐条核对、**导出 Excel**，以便上报"本月动态"。
4. 作为**园区领导**，我要查看**各园区**的签约金额、落地项目数及（可选）**年度目标完成率**对比，以便定位进度落后园区。

## 3. 口径定义（务必以本表为准）

### 3.1 时间与"当月"

- **签约时间**：取签约阶段记录的`签约审核通过时间`（Excel 序列数或 yyyy-MM-dd 字符串均需解析）。
- **落地时间**：取落地阶段记录的`落地审核通过时间`（即项目"转落地"通过的时间），作为"当月落地"判定依据。
- **统计区间**：页面统一的起止年月筛选（默认覆盖当前数据可用范围：2026-03 ~ 2026-07）。
- **"当月签约/当月落地"**：按当前所选统计区间的**末月**（区间结束月份）判定并展示；标题随区间联动标注，如"当月签约项目 · 2026-07"。
  - 说明：若用户将区间首尾设为同一月份，则区间累计即等于当月，行为一致、口径无歧义。

### 3.2 统计对象与指标

| 指标 | 统计对象 | 关键字段 | 计算方法 |
| --- | --- | --- | --- |
| 签约项目数（个） | mock `qianyue`（签约阶段有效记录） | `签约审核通过时间`、`是否已签约` | 区间/月份内签约审核通过的项目计数 |
| 签约金额（亿元） | 同上 | `投资金额(亿元)` | 对应项目求和（口径标注：以协议投资额/投资金额计） |
| 落地项目数（个） | mock `luodi`（落地阶段有效记录） | `落地审核通过时间` | 区间/月份内转落地通过的项目计数（即"开工开业项目"口径） |
| 当年到位资金（亿元） | 签约+落地记录中的到资数据 | `当年到位资金情况(亿元)`（缺省回退 `到资金额(亿元)`） | 区间内记录求和（跨阶段去重口径：按项目编号去重后再求和） |
| FDI 项目数（个） | 各阶段项目 | `是否FDI === "是"` | 计数（金额缺失，暂不展示 FDI 金额，见 §8） |
| 园区维度 | 项目所属园区 | `负责单位`（回退 `报送区`/`申报人`前缀） | 分组键；归属列表：生物城/未来城/综保区/光电园/服务业园/智造园/中华园/中心城/其他 |

### 3.3 剔除与去重规则

- **退库项目不计入**签约/落地统计（`_stage === 'tuiku'` 或退库状态记录过滤），仅页面可选提供"累计退库数"提示位。
- 同一项目在在谈/签约/落地各阶段独立成记录（mock 中项目重复出现为正常）；**签约统计只取签约阶段记录**，落地统计只取落地阶段记录，避免跨阶段重复计数。
- 到资统计跨阶段求和前按`编号`去重。

## 4. 页面结构设计

### 4.1 布局总览

```
[ 统计看板 · 项目统计分析 ]                      ← 由"项目维度看板"重构而来

┌─ 筛选条（时间区间筛选，全局联动）───────────────────────┐
│ 起始年月 [2026-03]  结束年月 [2026-07]  快捷：今年至今/上半年/全部   [查询] [重置] │
│ 当前区间：2026-03 ~ 2026-07（共5个月） · 本月明细口径：2026-07        │
└──────────────────────────────────────────────────┘

┌───────────────┬───────────────┬───────────────┬───────────────┐
│ 区间签约项目数 │  区间签约金额  │  区间落地项目数│ 当年到位资金  │   ← 4 张通报口径 KPI 卡
│   82 个       │  ∑亿元         │  10 个        │  ∑亿元         │
└───────────────┴───────────────┴───────────────┴───────────────┘

┌───────────────┬───────────────┬───────────────┬───────────────┐
│ 区间 FDI 项目数│ 当月签约(2026-07)              │ 当月落地(2026-07)              │
│   1 个        │   项目数 X · 金额 Y 亿元   [明细]│   项目数 N              [明细] │
└───────────────┴───────────────┴───────────────┴───────────────┘

┌─────────────── 月度趋势（区间内逐月）───────────────┐  ┌─ 各园区对比 ─┐
│ 双轴：签约项目数(柱)+签约金额(折线)；落地项目数另柱    │  │ 签约金额 落地数 │
└───────────────────────────────────────────────┘  │ （+目标完成率） │
┌─────────────── 明细区 ──────────────────────────────┴───────────────┘
│ [当月签约明细] [当月落地明细]   合计：X个 / 金额Y亿     [导出Excel] │
│  表格（序号/项目名称/负责单位/时间/金额/状态…）                      │
└────────────────────────────────────────────────────────────┘
```

### 4.2 筛选条件

| 控件 | 类型 | 说明 |
| --- | --- | --- |
| 起始年月 / 结束年月 | antd `DatePicker.MonthPicker` ×2 | 必选，默认 2026-03 / 2026-07；校验 start ≤ end |
| 快捷范围 | 预设按钮 | "今年至今"（2026-01~当前数据月）/ "上半年"（01~06）/ "全部" |
| 查询 / 重置 | Button | 重置回默认区间 |

### 4.3 指标卡（KPI）

- 卡片一「区间签约项目数」：区间内签约审核通过项目个数。
- 卡片二「区间签约金额」：对应`投资金额(亿元)`合计（单位：亿元，保留 1 位小数）。
- 卡片三「区间落地项目数」：区间内转落地项目个数（注明"=开工开业项目口径"）。
- 卡片四「区间当年到位资金」：Σ 到位资金（单位：亿元）。
- 卡片五「区间 FDI 项目数」：`是否FDI=是` 计数。
- 卡片六/七（成对，突出当月）：「当月签约项目」「当月落地项目」——数值 + 金额/计数，右侧"查看明细"按钮锚定到明细区并切到对应 Tab。
  - 当月签约项目数为 0 时置灰并显示"--"，不允许导出空表（提示"该月暂无签约项目"）。

### 4.4 图表

1. **月度签约/落地趋势**（区间内逐月）
   - 柱状：每月签约项目数；折线：每月签约金额；辅助柱：每月落地项目数。
   - 交互：点击某月柱子 → 明细区自动切换到"当月签约明细"，区间结束月临时改为该月。
2. **各园区区间累计对比**（对齐通报"各园区情况"）
   - 分组柱状：签约金额（亿元）+ 落地项目数（右轴或双图）。
   - 若已配置年度目标（见 §4.6），同图或以表格列展示"签约金额目标/完成进度"，落后时序（<50%）标红。
3. **（可选）当月分布辅助**：当月签约项目按产业类别/招商类型小饼图——二期迭代项。

### 4.5 当月明细表

明细区两个 Tab：

**当月签约明细**（末月口径）字段列：
序号（固定左列）/ 项目名称 / 负责单位（园区）/ 签约时间 / 投资金额(亿元) / 协议类型 / 是否注册 / 申报人 / 到资金额(亿元)

**当月落地明细** 字段列：
序号 / 项目名称 / 负责单位（园区）/ 落地时间 / 开工开业类型 / 投资金额(亿元) / 当年到位资金(亿元) / 申报人

行为要求：
- 顶部显示合计（X 个、签约金额 Y 亿元）；
- 每条记录可点击"查看"跳转对应阶段详情页（复用 `qianyue/detail/:id`、`luodi/detail/:id` 路由）；
- 分页 10 条/页，支持按项目名称搜索；
- **导出 Excel**：导出当前 Tab 全量明细（.xlsx），文件命名如 `2026年7月签约项目明细.xlsx`。

### 4.6 年度目标完成率（配置型扩展项）

- 由于系统当前无"目标值"，提供**园区年度目标配置**入口（系统管理下"统计目标配置"或页面右上角设置），维护各园区当年：
  签约金额目标（亿元）、落地项目数目标（个）、到位资金目标（亿元）。
- 配置后，"各园区对比"追加"完成率"列并支持按完成进度排序；未配置目标的园区不显示完成率，避免误导。
- 若评审后认为维护成本高，可将该项降级为二期，本版以"数量+金额+到位资金+FDI"完成汇报（见 §7 路线）。

## 5. 非目标（Non-Goals）

- 不做与项目数据无关的统计：见商/出差、招商活动、"周周有签约"、活动场次、项目线索、国企基金/尽调出资。
- 不做绩效打分与考核排名（保留现有"绩效维度看板/绩效考核"）。
- 不做跨园区项目重复归并的"共享计分"（同一项目只归负责单位一个园区）。
- 不在本版提供 FDI **金额**统计（数据缺字段，见 §8 风险）。
- 不做多年度目标进度对比与预测。

## 7. 验收标准（Acceptance Criteria）

1. 页面顶部提供起止年月筛选，默认覆盖当前数据月份；修改区间后，KPI、月度趋势、园区对比、当月卡与明细表同步刷新。
2. 总览卡片正确输出：签约项目数与签约金额、落地项目数、当年到位资金、FDI 项目数（以 §3 口径，可对抽样月份人工验算一致）。
3. "当月签约项目/当月落地项目"按区间末月统计；点击"查看明细"能定位到对应明细 Tab。
4. 当月签约明细、当月落地明细两张表字段齐全、合计正确、可按项目名称检索、可分页、可导出 xlsx；空月份给出明确空态提示。
5. 各园区对比图正确展示并标注完成率（若有目标配置）。
6. 详情跳转（明细行→签约/落地详情页）可用。

## 8. 风险与开放问题

| 风险/问题 | 影响 | 建议 |
| --- | --- | --- |
| FDI 金额无字段 | 无法给"FDI 万美元" | 本版仅给 FDI 个数；如需金额，扩展字段或二期接入 |
| 落地记录部分缺少落地审核通过时间 | 这些项目进不了"当月落地"统计 | 补齐 mock/转落地时落库该字段；本期验收以已有时段（6-7月）为准 |
| 目标值无数据源 | 完成率需要先配置目标 | 提供目标配置入口；或降级二期 |
| 数据为 2026 单年度 demo | 快捷"今年至今"等边界依赖年份 | 工具函数按数据实际最小/最大月兜底 |
| "当月"采用区间末月口径，与"自然月当前月"不同 | 语义需在页面上显著标注 | 页面文案固定写"当月（区间末月）"，区间为单月时即自然月 |

## 9. 迭代路线

- **MVP（本版）**：时间区间筛选 + 5 张通报口径 KPI 卡 + 当月签约/落地卡 + 月度趋势图 + 园区对比图 + 当月签约/落地明细表与导出。
- **v1.1**：年度目标配置与完成率；当月按产业类别/招商类型辅助分布；明细行内联编辑口径。
- **v2.0（如未来接真实数据）**：对接市级平台数据接口/更新频率说明；FDI 金额口径；同比环比。
