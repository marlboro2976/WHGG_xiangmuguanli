## 1. 背景与目标

### 1.1 问题

一线招商人员在月度/阶段汇报中，需要把项目的时间线（阶段流转、进展汇报、决策节点）人工翻阅、归纳成一段汇报文字，工作量大且口径不统一。

### 1.2 目标

系统读取项目在**所选统计区间**内的进展记录，自动提炼并生成**结构化汇报段落**：

- 降低一线人员撰写月度/阶段汇报的时间；
- 摘要口径统一、信息不漏（阶段变化、重要节点、风险）；
- 结果可编辑、可复制、可另存，人员对输出有最终控制权。

### 1.3 非目标（本期不做）

- 不做批量生成（多项目/园区汇总）——下期"先单后批"的批
- 不接真实大模型/后端（本期规则模板模拟 AI 效果）
- 不自动写回系统（除非用户确认"另存为进展汇报"）
- 不做跨模块数据权限改造

---

## 2. 用户与使用场景

| 用户 | 场景 |
| --- | --- |
| 园区/局办一线招商经办 | 月底前为单个重点推进项目生成"本月进展摘要"，粘贴进汇报材料 |
| 项目分管领导/汇总岗 | 在统计看板圈定区间后，进入某项目详情查看该区间提炼结果，判断口径是否可用 |

### 2.1 用户故事

1. 作为**招商经办**，我要选择/沿用某个月份区间，为项目生成"总体进展+节点变化+风险/下一步"的汇报段落，以便直接写入月报。
2. 作为**招商经办**，我要对生成文本做少量编辑并一键复制，避免格式不可控。
3. 作为**汇总人员**，我要知道摘要覆盖的时间范围与统计看板一致，避免区间口径漂移。

---

## 3. 输入数据与口径

### 3.1 数据来源（复用现有实体）

| 输入 | 来源 | 说明 |
| --- | --- | --- |
| 项目基础信息 | 各阶段详情页 project（mock 记录） | 项目名称、负责单位、投资金额、当前阶段 |
| 手动进展汇报 | 进展时间线 `normal` 条目 | 正文、汇报人、`updateTime`、所属阶段（月度更新文本主体） |
| 系统事件 | `system` 条目 | 新增、阶段流转（谋划→在谈→签约→落地）、导入、退库 |
| 决策节点动态 | `decision` 条目 | 节点通过/撤销等"● 决策节点更新" |
| 分派/反馈记录（可选辅助） | `AssignModal/FeedbackModal` 数据 | 二期再纳入风险/协调段 |

### 3.2 时间口径（用户已确认：跟随统计区间）

- 摘要数据范围 = "项目统计分析"页当前 **统计区间**（起止年月，全局共享）。
- 单项目生成时只取该项目进展记录中 `updateTime` 落在该区间内的条目。
- 若从未打开统计页，默认区间=数据可用范围（与统计页默认一致）。
- 标题与文首标注覆盖区间：`YYYY年M月`（单月）或 `YYYY年M月 ~ YYYY年M月`（跨月），字段名统一为"统计区间"。

> 联动方式：把统计页的"统计区间"抽成全局共享区间（模块级 store + 订阅），统计页每次查询写入选区间，进展摘要弹窗打开时读取；两处文案均标注当前区间，避免歧义。

### 3.3 范围与剔除

- 只摘要"落在所选区间"的记录；区间外历史记录不进入正文，但可在句尾补充"（历史累计：阶段 …）"（可选）。
- 已删除/已退库提示作为系统事件如实呈现。

## 4. 输出形态与生成规则（演示模板）

### 4.1 结构化汇报段落（四段式）

1. **【本月/本阶段总体进展】**：先一句概览（项目在 X 阶段，区间内共 Y 条更新、阶段是否推进），再浓缩 Z 条主要更新。
2. **【重要节点与阶段变化】**：系统事件与决策节点提炼（如 3-07 项目由在谈转入签约阶段；3-12 决策节点"投资协议审核"通过）。
3. **【风险与待协调】**：命中风险词（待/尚未/滞后/协调/卡点等）的进展内容摘录；无则写"暂无重大风险"。
4. **【下一步建议】**：基于最近一条进展的收尾句与当前阶段惯例提示（如"建议持续推进注册/开工手续"），空则提示"请人工补充下一步计划"。

### 4.2 生成规则要点（无 LLM，确定性模板）

| 情况 | 规则 |
| --- | --- |
| 区间内无任何记录 | 不允许生成，提示"所选区间内暂无进展记录，请调整统计区间" |
| 手动汇报 ≤3 条 | 全部提炼进总体进展 |
| 手动汇报 >3 条 | 按时间取关键 3 条 + 追加"另有 N 条日常更新" |
| 同内容多条 | 相似正文（按去空白相似度>0.8）去重 |
| 系统事件 | 转成"日期 + 阶段流转/动作"单句 |
| 决策节点 | 转成"决策节点『标题』已通过/更新"单句 |
| 风险词命中 | 独立进入风险段并加"⚠" |
| 汇报人 | 生成句尾可标注"（来源：XXX 汇报）"便于溯源，用户可编辑删减 |

### 4.3 演示"智能提炼"文案库

- 预置与判重场景一致的提示词/模板化文案，输出自然度以纯前端模板可达为准；真实大模型接入列入二期（预留 `generateSummary(items, range)` 纯函数接口，便于后续替换成 API）。

## 5. 交互设计

```
项目详情页 → 进展区顶部右侧按钮【AI 生成进展摘要】
  └─ 弹窗（宽 720~800）
      ├ 顶部：当前统计区间 2026年3月~2026年7月（全局联动）+ [重新生成]
      ├ 摘要正文（四段式，可编辑 TextArea，最多2000字）
      └ 底部：[复制文本] [另存为进展汇报] [关闭]
```

- **生成**：点击后按区间读取项目进展 → 模板引擎生成 → 填充可编辑文本。
- **复制**：navigator.clipboard 复制整段（保留四段标题换行）。
- **另存为进展汇报**：确认后作为一条 `normal` 进展写入本项目进展列表（时间=当前，内容="【AI摘要】…"，汇报人=当前用户，标记可溯源前缀），成功后时间线即时刷新。
- 空区间、跨多个月份的文案、以及"生成中"loading 状态（延迟数百 ms 模拟）均需覆盖。

## 6. 演示实现要点

- 新增纯函数引擎 `src/utils/progressSummary.js`：入参 `{ project, items, range }` → 输出四段文本；便于后续替换真实模型 API。
- 全局区间共享：新建轻量 `src/store/statsRangeStore.js`（模块级 start/end + subscribe），统计页与摘要弹窗共用；统计页查询/快捷项均写入选区。
- 详情页进展区按钮 + 弹窗组件 `src/components/ProgressSummaryModal.jsx`；沿用 `progressModalProps`/uiStyles 统一风格。
- 复制、另存需与本项目现有 message 反馈一致。

## 7. 验收标准

1. 打开统计页选区间 2026-03~2026-07 后，进入任意有进展的项目详情，AI 生成按钮可见。
2. 摘要四段结构完整；总体进展提及区间内主要汇报，节点段覆盖系统流转与决策节点，风险段仅在有风险词时出现。
3. 生成文本可编辑、可复制；复制内容粘贴后保留段落标题与换行。
4. "另存为进展汇报"后时间线新增一条且可溯源（含 AI摘要 前缀与生成人）。
5. 区间内无记录时给出明确提示且不产出空摘要。
6. 单月区间标题为"YYYY年M月"，跨月为"YYYY年M月 ~ YYYY年M月"，与统计页显示一致。

## 8. 风险与开放问题

| 风险/问题 | 影响 | 建议 |
| --- | --- | --- |
| 真实模型未接入 | 摘要为模板规则生成，语言较机械 | 一期接受；引擎纯函数化便于二期替换 API |
| 进展数据以详情页本地 state 为主 | 跨页面一致性依赖现有存储 | 先在详情页种子数据内取数；后续统一进展 store |
| 区间过宽（>6 个月） | 正文过长 | 默认折叠"另有 N 条"，正文仅保留关键 |
| "另存为"会改动项目进展 | 数据篡改风险 | 加确认弹窗 + 内容带【AI摘要】前缀；权限沿用当前人编辑规则 |
| 风险词库误判 | 风险段可能误报 | 词库精简（待/尚未/滞后/协调/卡点），用户可编辑结果兜底 |

## 9. 口径修订（2026-09-03 确认）

- **单项目自动总结**：改为按**当前自然月**（本月）时间维度总结，不再跟随统计区间；本月无进展记录时提示"本月暂无进展记录"，不生成空摘要。
- **统计面板（项目统计分析页）总结**：新增"AI 招商进度总结"，**跟随查询主体与查询时间**（起止区间），正文参考《20260601 通报》格式：
  1. 一、全区/园区招商总体情况（截至查询末月）：签约亿元以上项目数、签约金额、当年到位资金、当年开工（开业）项目数、FDI 金额（万美元）；
  2. 二、各园区招商情况：对比**年度考核目标**识别"超时序"园区（签约金额/到位资金/开工开业项目数/FDI 分项列出）。
- **超时序口径**：年初设年度考核目标，正常时序进度 = 年度目标 × 已过月份/12（如年度 12 亿，截止 6 月应达 6 亿）；完成值 > 正常应达进度即为"超时序"。年度目标值以通报附件1 预置为演示常量（标注口径，可按实际考核表替换）。
- 单项目弹窗不再读取全局统计区间；统计面板总结读取全局统计区间（主体+起止时间）。

## 10. 迭代路线

- **一期（本期）**：全局统计区间共享 + 详情页单项目 AI 生成（模板引擎四段式）+ 编辑/复制/另存
- **二期**：接入真实大模型 API；批量生成（园区/阶段汇总报告）；分派/反馈记录纳入输入；摘要结果沉淀与版本历史
